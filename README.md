## 🌟 系统核心功能与模块

本系统针对 **Sophia（敏捷直觉型）** 与 **William（探索慢热型）** 两位学生从 2026 年 3 月春季基础、暑期 10 节密集预备、到秋季开学第3周（Sophia 累计 25 节 / William 累计 19 节）的真实表现，量身打造全方位学情追踪与干预平台：

### 1. 📊 学情全貌与双人对比 (Overview & Comparative Analytics)
- **多视角一键切换**：支持「👥 双人对比视图」、「🌸 Sophia 个人专属」、「⚡ William 个人专属」。
- **五维核心能力雷达图**：量化对比 *运算流畅度*、*概念严谨性*、*代数空间建模*、*解题步骤规范度*、*专注与持久力*。
- **全历程课堂正确率走势（24个时间槽主时间轴）**：完整追溯春季袋鼠C集训、1v1拔高、暑期预备衔接班（双人同堂10节均分70.5% vs 49.0%）、秋季开学的表现波动与回升曲线（80%~85% vs 70%~75%）。
- **课堂生态与结对策略**：剖析互助机制，制定“Sophia 引导思路步骤、William 细致验算复核”的互补分工，并落实 35-10-35 分段抗干扰机制。

### 2. 🕸️ 三轨融合高交互知识图谱 (Knowledge Graph View)
- **36个小学三至六年级全景知识节点拓扑**：全面覆盖五大阶段知识域：
  - 阶段一：基础数感与四则运算（多位数竖式、带余除法、BODMAS运算顺序、数位Tens vs Tenths）
  - 阶段二：小数概念与数位百分数（小数加减乘除、有效数字精度6 vs 6.0、百分数位移）
  - 阶段三：分数意义与通分运算（假带互化、商不变原理、最简分数、异分母通分、残差巧比大小、倒数乘除）
  - 阶段四：因数倍数与方幂代数（整除、质数合数、整除判定、短除法质因数分解、HCF/LCM、完全平方数、同余压轴、乘方本质、指数法则、科学记数法）
  - 阶段五：几何度量与应用建模（周长、正方形面积反求边长、度量衡进率、行程问题、大题审题三部曲、折纸模型）
- **前置后继学习依赖链**：基于 SVG 动态贝塞尔曲线连接与流动箭头，清晰展示知识递进关系。
- **动态掌握热力着色**：根据学生视角实时呈现 ★ 熟练掌握（绿）、☆ 掌握良好（蓝）、△ 亟待攻坚（橙红）、○ 待学新课（灰）。
- **学情抽屉交互 (Node Drawer)**：点击任意节点即滑出侧边栏，展示中英双语考点对照、学情突破点及历史关联错题。

### 3. 📕 经典错题与深度解析库 (Error Bank & Deep Solutions)
- **29道真实课堂全结构化错题卡**（Sophia 12题 / William 17题）：
  - 🔴 **极高危/断层级 (9题)**：通分分子未同步相乘、18+5=90低级失误、乘方当乘法、同底数幂指数相乘、数位Tens vs Tenths搞反、0.9+0.1=4.1进位失控、5.4÷0.6=0.9移位搞反、分数除法当乘法2/8=16、比例变形比号当乘号；
  - 🟠 **高危/机制级 (13题)**：质数严格定义漏只能、HCF/LCM指数加总、带余除法52÷24写24又4/2、倒数法则不同步、有效数字漏中间0、同分母加法分母乱相加3/6+5/6=8/12等；
  - 🟡 **中危/规范级 (7题)**：周期循环忽略播放起点、新定义运算漏负号、短除法试除合数6、大数整除漏解X、行程应用空题等。
- **三级危险度筛选器**：支持按学生、危险等级（🔴极高危/🟠高危/🟡中危）、错误分类及实时全局关键词搜索。
- **名师记忆口诀 (Teacher Mnemonic)**：针对薄弱点提炼通俗好记的记忆口诀。
- **知识图谱无缝联动**：每道错题均配有「📍 在知识图谱中定位对应考点」按钮，可一键跳转并定位至关联知识节点。

### 4. 🎯 教学路线与专属干预方案 (Progressive Roadmap & Actions)
- **四阶段进度路线图**：开学半月基础衔接 $\to$ 国庆前后分数精通 $\to$ 期中前后比与比例应用 $\to$ 期末三轨闭环冲刺。

## 🛠️ 技术架构

- **前端架构**：原生 HTML5 + 现代化 CSS3（Glassmorphism 毛玻璃设计系统、CSS Variables、Fluid Grid、Flexbox）
- **动态渲染**：原生 JavaScript (ES6+)、SVG 矢量拓扑图谱平移缩放引擎、HTML5 Canvas 2D 高清渲染（雷达图、折线走势图）
- **数学排版**：KaTeX 数学公式渲染引擎（支持 LaTeX 专业公式展示）
- **无依赖部署**：零外部构建步骤，即开即用，完美兼容静态托管与本地脱机运行。
