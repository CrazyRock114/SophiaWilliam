18. (1) 0 或 5（1分）； (2) $1000X = 1001X - X = 13 \times 77X - X \equiv -X \pmod{13}$（2分）； (3) 余 7； 需满足 $7 + Y - X$ 能被 13 整除（2分）； (4) 分类求解（3分）：
分支一：若 $Y = 0$，则 $7 - X \equiv 0 \pmod{13}$，因 $0 \le X \le 9$，解得唯一数字 $X = 7$；
分支二：若 $Y = 5$，则 $12 - X \equiv 0 \pmod{13} \implies X = 12$（非单数字）或 $12 - X = 13 \implies X = -1$（舍去），无解；
